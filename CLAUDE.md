# multipaas CLI

## Client surfaces

A change to something a builder sees (a command, a flag, what a command prints, or sign-in) updates the public docs on
multipaas.com in the same story. The docs change is its own PR in
[MultiPaaS-Apps/website](https://github.com/MultiPaaS-Apps/website), linked from this repo's PR. A change with nothing
user-visible needs no docs change.
